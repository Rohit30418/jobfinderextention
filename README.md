# JobPilot

Stage 1 of JobPilot: build and validate a reusable candidate profile from a resume.

Current scope:
- Upload PDF / DOCX / TXT / MD
- Paste resume text fallback
- Validate extracted text before saving
- Preview and edit extracted text
- Review/edit profile
- Save locally with chrome.storage.local
- Replace or delete resume/profile
- Developer diagnostics

Job portal search, matching, inline badges, and job scoring are intentionally not included yet.
