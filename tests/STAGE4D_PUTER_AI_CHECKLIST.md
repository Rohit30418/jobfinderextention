# Stage 4D — Puter AI JD enrichment

## Preconditions

- [ ] A detail job is READY before AI can run.
- [ ] Puter is connected.
- [ ] Puter AI permission is authorized.
- [ ] Listing pages do not send 20 jobs to AI.

## AI input

- [ ] AI receives only the normalized current job and clean JD text.
- [ ] Portal facts remain authoritative.
- [ ] AI does not overwrite title/company/location/salary/experience.
- [ ] Missing evidence stays empty.

## AI output

- [ ] Role family
- [ ] Seniority
- [ ] Domain
- [ ] Required skills
- [ ] Preferred skills
- [ ] Must-have requirements
- [ ] Nice-to-have requirements
- [ ] Responsibilities
- [ ] Explicit disqualifiers
- [ ] Education requirements
- [ ] Work mode
- [ ] Employment type
- [ ] Experience interpretation
- [ ] Summary
- [ ] Short evidence snippets

## Persistence

- [ ] AI analysis is saved on the normalized job.
- [ ] Opening Stage 4 again preserves the AI analysis.
- [ ] Portal recapture does not erase AI analysis.
- [ ] Listing/detail identity merge does not create a duplicate AI record.

## UX

- [ ] Connect Puter button
- [ ] Authorize AI button
- [ ] Analyze current job with AI button
- [ ] Disconnect button
- [ ] Clear success/error message
- [ ] No match percentage is shown.
- [ ] AI enrichment is visually separated from extracted portal facts.

## Out of scope

- [ ] No candidate/job match score yet.
- [ ] No auto apply.
- [ ] No automatic AI call for every listing card.
